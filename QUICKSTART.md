# ⚡ Quick Start Guide

Быстрый старт за 2 минуты.

## 🎯 Запуск за 3 команды

```bash
# 1. Установить зависимости
pnpm install

# 2. Поднять БД и применить миграции
make db-up && sleep 5 && make migrate-dev

# 3. Запустить приложение
make dev
```

Откройте http://localhost:3000 🚀

## 📝 Создание первого отчета

1. На главной странице нажмите **"Создать отчет"**
2. Заполните название и клиента
3. В редакторе добавьте блоки:
   - Кнопка **"Добавить блок"** справа
   - Выберите "Текстовый блок" или "Блок с фото"
4. Напишите текст с Markdown:
   ```markdown
   # Заголовок
   
   **Жирный текст** и *курсив*
   
   - Пункт 1
   - Пункт 2
   ```
5. Для фото: загрузите изображения через drag & drop
6. Нажмите **"Сохранить"**
7. Перейдите в **"Просмотр"** и экспортируйте **PDF**

## 🗃️ Тестовые данные

```bash
# Заполнить БД примерами отчетов
pnpm prisma:seed
```

Будет создано 2 тестовых отчета с блоками.

## 🐳 Docker (альтернатива)

Если Docker установлен:
```bash
make up
```

Всё поднимется автоматически (БД + приложение).

## 🔧 Полезные команды

```bash
make help           # Показать все команды
make logs           # Логи приложения
make prisma-studio  # Открыть UI для БД
make migrate-reset  # Сбросить БД (если что-то сломалось)
```

## ❓ Проблемы?

### БД не подключается
```bash
make db-down && make db-up
```

### Ошибка миграций
```bash
make migrate-reset
```

### Playwright не работает
```bash
pnpm playwright:install
```
